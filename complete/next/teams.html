Before you start

Agree on the operating rules.

Check the fit for your tools, permissions and deployment.

Can every developer change the team cap?

Organization budget changes require the relevant administrator role. Members need to understand their allowance and the escalation path; editing permissions are separate.

Does observe mode switch all controls off?

Observe mode leaves routing substitutions off. Security and budget controls have their own monitor or enforce settings; review each before the pilot.

When should we add more people?

After you can identify the supported traffic, explain costs, inspect quality evidence and resolve setup problems for the first group. Doorman does not guarantee a fixed saving or unchanged answer quality.

Can we govern agents as well as people?

Visible model calls, registered MCP tools and A2A peers have different policy boundaries. Managed provider agents expose a call boundary rather than every internal step. Map the agent interfaces ↗

Do we have to replace our existing router?

A pilot can run alongside an existing router or evaluate a supported chained path. If many users share one upstream credential, do not assume the chain preserves individual identity; review organization-level scope and attribution separately. Compare connection paths ↗
