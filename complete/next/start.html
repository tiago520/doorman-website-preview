Your starting point

You are preparing a local checklist: choose the environment, enter the gateway origin, then review and download the client settings. It does not create an account or provision infrastructure.

Your connection

Enter only the origin, such as https://gateway.example.com, without a path, query or embedded credentials. Use the value from your administrator; localhost HTTP is for development.

Review before applying

Review the endpoint, replace YOUR_DOORMAN_KEY locally, and apply the settings in the process that launches the client. Then send one non-sensitive request and verify it in your own console.

Before applying settings

Keep the first test simple.

Change one client, send one harmless request, then inspect the evidence.

Do I paste my key into this website?

No. The assistant generates a symbolic key value. Replace it locally in your approved secret-handling flow; do not put production secrets in a shared worksheet or the public demo.

Does this install or launch the Mac app?

No. The assistant prepares client settings only. The Go + Swift companion has separate build, helper and availability requirements. Read the Mac setup guide ↗

The client works, but no request appears.

Confirm the client restarted with the intended endpoint and that you are viewing the correct gateway and organization. Refresh the request list, then review client-specific configuration before changing more settings. Troubleshoot the connection ↗
