Managed networks

Fit the controls already in place.

For Zscaler, Cisco and other secure-web-gateway environments, validate forwarding, identity and certificate requirements with the administrator. A desktop install is not proof that every tool is governed.

Does a certificate-pinned app become governable?

Not automatically. Some tools remain visibility-only. Verify supported coverage rather than assuming interception worked.

Is the native macOS installer available here?

The current Go app repository has no published signed release. The macOS guide distinguishes source-build evaluation from a customer-ready installer.

Can we use a private or on-premises deployment?

Bring residency, network isolation, provider reachability and operations requirements to the deployment review. Confirm the available package and support model for your environment; the sample website is not evidence that an air-gapped distribution is available.

Who needs to be involved in an enterprise pilot?

Include the client or endpoint owner, gateway operator, identity administrator and security reviewer. For secure-web-gateway forwarding, include the network team. Finance joins when allocation and budget controls are part of the success criteria.

What changes when employees use subscriptions or GUI tools?

An API-key CLI with a configurable endpoint is the simplest path. Subscription authentication, GUI apps without endpoint settings and certificate pinning need separate coverage checks. Some supported subscriptions preserve their own authentication; a pinned app can remain observed only. Record each path and its limits in the pilot.

Can we keep LiteLLM during the pilot?

Yes. Keep application inference on its existing path and evaluate supported employee tools separately. If you configure a chain, choose one first hop and verify credentials, protocol and organization policy. A shared upstream key does not preserve end-user identity; imported cost tags are attribution, not authentication.

Leave with a testable rollout plan.

Bring your client inventory, network owner and identity requirements. Define the first pilot, its success checks and recovery path.
