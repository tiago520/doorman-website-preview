Before you start

Count delivered savings, not proposed shortcuts.

Keep token reduction, model selection and provider discounts separately accounted for.

Does the batch option deliver async jobs today?

Current batch support records explicit eligibility and defines provider request shapes. The submit/poll/retrieve lifecycle is documented as deferred; this page does not promise a working managed batch service.

Do you count my existing cache discount?

It is recorded separately from Doorman-attributable savings. The savings breakdown also exposes qualifying retry adjustments and charges for tuned-model inference.

Are all reports the same savings number?

No. The routing history and all-time contribution breakdown cover different periods and mechanisms. Compare the period and contribution labels before reconciling them to a finance report.

Where do subscription seats fit?

A subscription pool selects among eligible credentials; it is a different mechanism from token reduction. Supported provider lanes and account terms must be reviewed. Review subscription-seat access ↗

Does embedding reuse change the vector model?

No. Exact reuse keys include organization, model, input and request shape such as dimensions. A different model or shape needs its own result. This preserves vector compatibility instead of silently replacing the embedding model.

Can compression remove useful details?

Any transform needs representative task checks. Tool-output compression defaults off; monitor mode leaves the body unchanged, while apply mode transforms eligible content. Unsupported paths or transform failures retain the original. Verify a compression trial ↗
