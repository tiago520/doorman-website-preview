Your first Mac

One place to start and check.

Use the app for the everyday steps, with a named owner for anything your team needs to prepare.

01 · Preview access

Get the supported build.

Request access for a Mac running macOS 14 or later. Doorman or your IT contact supplies the evaluation build and its installation instructions.

02 · Browser sign-in

Review the account.

Continue with Google in your browser, return to the app and confirm the email shown. Follow any permission instructions supplied for that build.

03 · Everyday checks

See what is ready.

Open View apps to inspect your tools. Use Check this Mac to review the account, background helper and any setup that still needs attention.

The current preview supports sign-in and diagnostics; automatic tool configuration and routing are still being built. A signed public installer and production MDM package are not published yet.

Your starting point

This local assistant prepares settings and a downloadable checklist. Choose the environment, enter your gateway origin, then review the client recipe.

Your connection

Enter only the origin, such as https://gateway.example.com, without a path, query or embedded credentials. Use the value from your administrator; localhost HTTP is for development.

Review before applying

Review the endpoint, replace YOUR_DOORMAN_KEY locally, and apply the settings in the process that launches the client. Then send one non-sensitive request and verify it in your own console.

Before applying settings

Keep the first test simple.

Change one client, send one harmless request, then inspect the evidence.

Do I paste my key into this website?

No. The assistant generates a symbolic key value. Replace it locally in your approved secret-handling flow; do not put production secrets in a shared worksheet or the public demo.

Does this install or launch the Mac app?

No. The assistant prepares client settings only. Use the Mac preview path above for the native app and its supplied installation instructions. Read the Mac setup guide ↗

The client works, but no request appears.

Confirm the client restarted with the intended endpoint and that you are viewing the correct gateway and organization. Refresh the request list, then review client-specific configuration before changing more settings. Troubleshoot the connection ↗
