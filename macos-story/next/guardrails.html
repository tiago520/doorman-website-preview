Before you connect

Know what the control covers.

Are streaming responses blocked or redacted?

These output controls enforce supported non-streaming responses. Streams are monitored and audited after delivery.

Does tokenization catch every secret?

No. It detects configured entity patterns on supported paths. Detection is not comprehensive, and a transform failure can pass the original request through.

Do regulatory presets certify compliance?

No. Presets select detector categories. Compliance depends on your deployment, processes and obligations, not a preset name.

How does this help a retrieval or RAG application?

The retrieval rail inspects selected context for unsafe content. Tagged context gives the application an explicit boundary; automatic recognition uses heuristics. Choose monitor, sanitize or block behavior deliberately and test ordinary context too. The retrieval setup guide explains the integration.

How should a team review false positives?

Use fictional examples first, inspect the finding and compare the intended action with the result. Backtest changes on eligible recorded traffic and review misses as well as detections. Detection and transformation failures may pass through, so enforcement needs a supported-path test.

Test the policy on your actual path.

Choose one data type and a representative workflow. Review detections, missed cases and the action your users will experience.
