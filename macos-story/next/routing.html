Routing decisions

Understand preview, observe and live behavior.

Does Doorman Advisor replace the primary model?

No. The primary model can consult a configured advisor during generation and use its advice in the final answer. This opt-in beta is off by default and requires request, deployment and organization eligibility. Consultation limits, data checks and cost records make the extra work reviewable; evaluate total cost and quality before adoption.

Does Route preview call the provider?

No. It shows a routing decision and estimated cost without an upstream model request. It does not predict answer quality or simulate runtime budget enforcement.

Will every request use a cheaper model?

No. Routing depends on the request, policy, confidence and supported path. A request can keep its original model or pass through. There is no fixed saving guaranteed for every workload.

Does observe mode disable every policy?

No. Observe mode disables routing substitutions; data protection and other policies keep their own settings. This mode is gateway-wide and needs the gateway operator’s approval on a shared deployment. Organization routing preferences are a separate control.

Can we use schedules or override a routing choice?

Routing schedules let an authorized owner manage ordered time windows and the applicable routing settings. Model allowlists and explicit pins have their own scope. Preview representative cases, then verify real requests before relying on the rule. Inspect the sample schedule controls ↗
