# Doorman identity exploration

Three independent SVG directions created for owner review. The current logo and website were not changed.

## Recommended: Passage
An open D with a threshold cut into its base. Connects the name to controlled passage, with a simple solid silhouette and visible two-pixel opening at 16px. The strongest fit with the clean website.

## Alternative: Doorway
An architectural entrance and an open leaf. Warmer and more literal. Its asymmetry is intentional; the diagonal leaf adds personality but can imply a property or access-control product.

## Alternative: Switch
Two offset gates leave an open passage. Most abstract and technical. Strong standalone app silhouette; less immediate connection to the name until learned.

## Files
`assets/<direction>-icon.svg`: monochrome master, 32-unit viewbox.
`assets/<direction>-16.svg`, `-24.svg`, `-48.svg`: exact interface-size exports.
`assets/<direction>-white.svg`: reversed master.
`assets/<direction>-wordmark.svg`: outlined Inter ExtraBold lockup, no font dependency.
`assets/<direction>-app.svg`: yellow app icon; `-app-ink.svg` and `-app-white.svg` are monochrome applications.

All SVGs include accessible titles. Geometry is original, vector-native, and editable. Color uses existing Doorman tokens only. The yellow app tiles are identity applications, not proposed extra yellow marketing sections. Wordmark spacing is a first optical pass; a chosen direction should receive final platform raster exports, small-size optical refinement.

Typography: Inter by Rasmus Andersson, SIL Open Font License (see assets/OFL.txt). The web sheet loads local fonts. No analytics, forms, external requests, or production actions.

## Preview
Serve this directory with any static server. `index.html` is the responsive comparison sheet. `comparison-desktop.png` and `comparison-mobile.png` show browser-rendered views.
