Existing app semantics. Proposed Switch treatments.

What comes from the app

The reference is the native macOS implementation in Sources/DoormanMenuBar/Glyph.swift, App.swift, and Sources/DoormanModel/Model.swift. It declares protected, reconnecting, attention, paused, managed, and signedOut. This identity study does not change app code or claim these treatments are already shipped.

StateNative behavior and Switch proposal
ProtectedA 0.6-second settle on entry follows the native protected transition.
ReconnectingA 1.5-second opacity wave adapts the existing seven-tile reconnect animation. “Loading” can share this motion only while connection or setup is actually pending.
PausedThe native paused state dims its tiles to 40% and outlines its door. Switch keeps the dimming and proposes two small pause bars.
Needs attentionA 1.8-second pulse follows native attention timing. The proposed marker replaces the displaced native corner tile; shape and text accompany color.
ManagedThe native managed state adds a gate bar across its door. Switch carries that bar through the central opening.
Signed outThe native signed-out state outlines its tiles and door. Switch uses the same outline convention.

Design decisions

The selected two-gate geometry is unchanged. Static states do not loop. Protection settles once; reconnecting and attention alone repeat. The demonstration’s motion control can stop all motion. Operating-system reduced motion disables animation regardless of that control.

“Protected” is the native state name, not a new claim that every tool is covered. Real product surfaces must retain their per-tool coverage details. “Managed” names organization control; it does not assert connection health. “Loading” is an interface transition, not a seventh helper state.

Menu bars show the selected state. Browser tabs and app icons stay neutral: a website favicon cannot verify local gateway health. Reversed and dark applications use the same geometry. The 16px exports retain the master’s exact proportions; final native rasterization should be checked at the app’s actual 18pt menu-bar size.

Files

The kit includes the neutral master, light/dark favicon, three app icon colors, outlined wordmarks, and six states at 16, 24, and 32 pixels. switch-state.css contains the proposed motion and reduced-motion fallback. Static SVG exports remain useful without JavaScript or animation.
