Before you start

Administration that reflects the actual setup.

Check the fit for your tools, permissions and deployment.

Are SSO and provisioning enabled automatically?

No. Identity providers, claims, provisioning and permissions need the appropriate deployment and configuration. Confirm the integration rather than treating an identity screen as proof it is connected.

Can every integration be connected here?

Webhook creation is supported in the console. Some ITSM destination setup actions are not implemented in this UI; confirm the supported administrator setup path before promising a one-click connection.

How long is our data retained?

Retention varies by plan and data type. The audit log shows its current retention window; do not assume that value covers all stored traffic or artifacts.

Can we automate administration?

Scoped Control API tokens are distinct from virtual keys used for model traffic. Limit token scope to the script’s management job. Explore API tokens ↗
