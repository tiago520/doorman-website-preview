Light and dark appearances cover the menu bar's six states, three first-run steps,
settings, app coverage, and diagnostics. All screens are HTML design mockups with
example data. Actions in the interactive prototype are simulated.

Based on the [approved Switch identity](https://tiago520.github.io/doorman-website-preview/next/branding.html).
Dark mode is a proposed extension of the website palette. Original assets and the
Inter font license are in `assets/`.

Published from DoormanAI/doorman-mac commit `36729d0`.
The prototype passed 44 rendering/accessibility cases and 12 interaction checks;
see [verification](exports/verification.json) and [export provenance](exports/provenance.json).
